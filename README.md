### 👨‍💻 About Me

I'm an AI / ML Engineer focused on building practical and production-oriented AI systems.

My work spans Machine Learning, Deep Learning, Generative AI, LLM applications, AI agents, MLOps, backend APIs, and cybersecurity.

I enjoy taking an AI/ML idea from data and model development to API serving, monitoring, containerization, and production deployment.

- 🔭 **Currently Building:** Production-ready AI/ML and GenAI applications
- 🤖 **Exploring:** LLM Orchestration, AI Agents, RAG, Tool Calling, Multimodal AI & LLMOps
- ⚙️ **MLOps Focus:** Model Versioning, Experiment Tracking, Model Serving & Drift Monitoring
- 🔐 **Cybersecurity:** Security fundamentals, OWASP concepts, security tooling & AI + cybersecurity applications
- ☁️ **Cloud & DevOps:** Docker, AWS, Git/GitHub & CI/CD fundamentals
- 💬 **Ask Me About:** Python, FastAPI, Machine Learning, PyTorch, RAG, LLMs, AI Agents, Docker & MLOps
